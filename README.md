# 🌊 Cauca Guardians: The River's Echo
### Los Guardianes del Río Cauca

Juego educativo retro tipo RPG ambientado en el Bajo Cauca antioqueño. Eres un Guardián: tu arma no es la violencia sino la **purificación**. Cura criaturas corrompidas, limpia el agua contaminada por basura, lodo y mercurio, y rescata la fauna del río.

- 3 niveles con jefe final: El Puerto de Caucasia · El Lodo Dorado · Las Profundidades del Mercurio
- Bilingüe (ES / EN), con botón de idioma
- Eco-Dex, tienda de mejoras, insignias y guardado automático (localStorage)
- Controles de PC y móvil (joystick táctil)

## Cómo jugar
- **PC:** WASD / flechas = mover · clic o ESPACIO = red filtrante · E = ráfaga de carbón activado · F = plantar semilla-puente
- **Móvil:** joystick + botones en pantalla

## Ejecutar localmente
Abre `index.html` en el navegador (requiere internet para cargar Phaser 3.60 y la fuente desde CDN).

## Publicar en GitHub Pages
1. Sube `index.html` y `README.md` a la raíz de tu repositorio.
2. En GitHub: **Settings → Pages → Build and deployment**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En 1–2 minutos estará en `https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/`.

## Tecnología
HTML + CSS + JavaScript, motor [Phaser 3.60](https://phaser.io/). Todos los gráficos se generan por código (sin imágenes externas).
